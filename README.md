# SOCIAL FILTER v2.1
**Privacy-Protected Social Media Profile Tracker**

## Installation

1. **Extract this ZIP file** to a permanent location (e.g., Documents/Extensions/social-filter)
   - DO NOT delete the folder after installing!

2. **Open Chrome** and go to `chrome://extensions/`

3. **Enable Developer Mode** (toggle in top-right corner)

4. **Click "Load unpacked"**

5. **Select the extracted folder**

6. **Done!** Extension icon should appear in your toolbar

## How to Use

**Track Profile Visits Automatically:**
- Visit any Instagram, TikTok, Facebook, Twitter, YouTube, Reddit, LinkedIn, or Snapchat profile
- Extension automatically logs the visit
- Click extension icon to see your history

**View Your History:**
- Click extension icon for recent visits
- Click "Open Full Dashboard" for complete history
- Search, filter, export, or delete entries

**Settings:**
- Toggle tracking ON/OFF
- Enable/disable specific platforms
- Set max entries or days to keep
- Clear all data

## Features

- 100% Local Storage (your data never leaves your device)
- Track 8 major social platforms
- Search and filter history
- Export as JSON or CSV
- Add notes to entries (great for OSINT)
- Automatic cleanup of old entries
- Beautiful dark interface

## Privacy

- All data stored locally on YOUR computer only
- Zero telemetry or data collection
- Not synced to cloud
- Contains non-intrusive affiliate ads (supports development)
- Ads do NOT track you

## Requirements

- Google Chrome or Chromium-based browser
- Chrome version 88 or higher

## Support

For issues or questions:
- Check the Privacy Policy tab in the extension
- Inspect console for errors: chrome://extensions/ → "Inspect views: service worker"
